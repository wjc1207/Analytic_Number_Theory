## About Analytic Number Theory

Analytic number theory is a branch of number theory that uses methods from mathematical analysis to solve problems about integers. It includes topics such as:

- Prime number theorem
- Distribution of prime numbers
- Riemann zeta function
- L-functions
- Dirichlet series
- And much more

This notebook serves as a practical guide for those who want to understand the core principles and applications of analytic number theory.
